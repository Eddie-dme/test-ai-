安装步骤

  1. 装过旧版请先长按图标卸载（签名已变更，无法覆盖安装）
  2. 点上方按钮下载 APK
  3. 若提示「禁止安装」，到
    设置 → 安全 → 安装未知应用
    允许浏览器安装
  4. 下载完成后点击文件安装
  5. 若被手机管家拦截，选「继续安装」
⚠️ 首次打开若显示空白：说明手机与电脑不在同一 WiFi。
请连上 ChinaNet-jkML-5G 后重试。
