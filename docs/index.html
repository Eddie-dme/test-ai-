What it is

An AI character roleplay app. Every character carries their own voice, history and opening scene. Conversations accumulate — a character who distrusted you in chapter one may hand you an apple by chapter five, and side stories unlock once your bond is deep enough.

What's inside

✦

Characters with a point of view

Five identities, ten personality traits, a three-thousand-character background, and an opening line that sets the scene. Each one speaks in their own register.

◈

Memory that holds

A memories panel for the details that matter — what they call you, what you told them, what they should never forget. A chat diary summarises the plot so far, so nothing important falls out of context.

❖

Bonds and hidden chapters

Affinity drifts with the emotional current of a conversation. Cross a threshold and side stories open — spoiler-free until you earn them, synced back into your memory once you've played them.

♪

They say it out loud

Every character has an individual voice. Tap to hear a line spoken — stage directions are stripped out before synthesis, so you hear dialogue, not narration.

◎

Rooms, scenes, moments

Open World mode for building your own setting. Scenarios, a moments feed, shared albums, quests and achievements — the parts you'd expect, done properly.

How it's built

Python (standard library only) SQLite Vanilla JS + CSS Server-sent events Android WebView Direct SDK toolchain build MiniMax-M3 Speech synthesis Image generation

No frontend framework, no build step, no web server framework. The service runs from a single Python file; the interface is one HTML document. See the repository for the architecture notes.
