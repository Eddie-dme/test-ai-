# Google Play 开发者账号注册建议

> 对应 Play Console 注册流程中的「关于您 / 您在 Play 管理中心和 Android 方面的体验」字段
> 更新日期：2026-09-21

---

## 一、这个字段是干什么的

Google 用它判断**申请人是否为真实的、有经验的开发者**，用于防范批量注册的垃圾 / 欺诈账号。

**「还未上线」四个字为什么危险**——同时踩了三个雷：

1. 信息量为零（4 / 5000 字符）
2. 明确表示没有任何作品
3. **无法验证** —— Google 核实不了你说的任何东西

对审核系统来说，这是「低质量申请」的典型特征。

---

## 二、填写策略：可验证 > 具体 > 真实

按证据强度排序，**有什么写什么**：

| 强度 | 内容 | 说明 |
|---|---|---|
| ★★★ | **已发布的应用** | 不限 Google Play —— 华为 / 小米 / OPPO / vivo / 应用宝 / App Store，附链接 |
| ★★★ | **代码仓库** | GitHub / Gitee，哪怕只有练手项目 |
| ★★ | 技术输出 | 技术博客（掘金 / CSDN / 个人站）、开源贡献 |
| ★ | 工作经历具体化 | 公司、职位、年限、产品类型 —— 具体到能被追问 |

## 三、可套用的模板

```
我是一名 Android 开发者，有 [X] 年移动应用开发经验，主要使用 Kotlin / Java。

[工作经历] 目前在 [公司类型] 担任 Android 开发，参与过 [产品类型]
的客户端开发，负责 [具体模块]。

技术栈：Android SDK、Kotlin、Jetpack、网络编程、应用内购（Google Play
Billing）与广告变现（AdMob）。

我目前正在独立开发一款 AI 角色扮演类应用，计划发布到 Google Play。

相关链接：
- GitHub：https://github.com/[你的账号]
- 技术博客：[链接]
- 已发布作品：[链接]
```

**要点**：

- **一定要附链接** —— 页面原文就写着「您可以添加相关证明资料的链接」，这是它最看重的部分
- 200–800 字符足够，不必写满 5000
- 语言跟随账号地区设置（中文账号写中文即可）
- 提一句你正在做的 App，让账号用途和开发者身份对得上

## 四、绝对不要编造

Google 具备交叉验证能力（尤其当你给了链接）。**造假会导致账号封禁且 $25 不退。**

宁可用真实但单薄的经历，也不要写漂亮却经不起核查的内容。

**如果确实没有任何可验证的作品**：去建一个 GitHub 账号，把 `floze_clone` 这个项目传上去。
这是一个真实、完整、能跑的项目，比任何文字描述都有说服力。

## 五、比这个字段更影响成败的三件事

### 5.1 个人账号 vs 组织账号

| | 个人账号 | 组织账号 |
|---|---|---|
| 费用 | $25 | $25 |
| DUNS | **不需要** | **必须** |
| 验证材料 | 身份证 / 护照 + 地址 | 组织文件 + DUNS |
| 开发者显示名 | 个人名 | 公司名 |
| 适用 | 个人产品 / 试水 | 公司商业产品 |

> **如果只是想把产品发出去验证市场 → 走个人账号，完全不用碰 DUNS。**

### 5.2 新个人账号的封闭测试门槛 ⚠️

新注册的个人开发者账号在发布生产版本前需要通过封闭测试
（我印象中是 **12 名测试者连续 14 天**）。

**这意味着就算账号明天批下来，还要再等两周才能上架。**
测试者招募是纯人工工作，且不需要账号 —— **现在就该开始攒名单**。

### 5.3 内容分级

你的产品对标 FlOZE（Mature 17+ / Sexual Themes）。这个分级会限制部分地区的投放。

**注册时如实填写分级问卷**，不要为了过审低报 —— 后期被抽查到会被下架。

## 六、DUNS 快速说明（若走组织账号）

- **先查重**：大公司做海外业务通常早就有 DUNS → `dnb.com/duns-number/lookup.html`
- **失败最常见原因**：名称 / 地址与营业执照不一致（中文名 vs 英文名、有无 "Co., Ltd."、省市区格式）
- **加速顺序**：查重 → 走 Google Play 专用通道（有加急）→ 信息逐字对齐 → 电话跟进 → 付费加急
- **不要找代理**：DUNS 官方免费，代理可能用不一致信息注册导致验证失败
