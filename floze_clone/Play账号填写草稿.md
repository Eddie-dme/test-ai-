> 用途：注册 Play Console 时的「您在 Play 管理中心和 Android 方面的体验」字段
> 状态：**待你补充真实信息**（下方 `[ ]` 处需替换）
> ⚠️ 不要编造——Google 会交叉验证，造假会导致账号封禁且 $25 不退

---

## 一、为什么这个字段重要

当前填的是「还未上线」四个字。这同时踩了三个雷：

```
信息量为零      4 / 5000 字符
明确无作品      主动声明没有开发经验
无法验证        Google 核实不了任何东西
```

对审核系统来说，这是「低质量申请」的典型特征。

**这个字段的真实用途**：判断申请人是否为**真实的、有经验的开发者**，以防范批量注册的垃圾/欺诈账号。

---

## 二、填写策略：可验证 > 具体 > 真实

|---|---|---|
| ★★★ | **已发布的应用** | 不限 Google Play —— 华为/小米/OPPO/vivo/应用宝/App Store，附链接 |

| ★★ | 技术输出 | 技术博客、开源贡献 |
| ★ | 工作经历具体化 | 公司、职位、年限、产品类型 |

**1. 一定要附链接**

**4. 提一句你正在做的 App**，让账号用途和开发者身份对得上

**5. 如果确实什么都没有 → 先建 GitHub 账号**

把 `floze_clone` 项目传上去（这是一个真实、完整、能跑的项目，比任何文字描述都有说服力）。

## 五、比这个字段更影响成败的三件事

### 5.1 个人账号 vs 组织账号

| | 个人账号 | 组织账号 |
|---|---|---|
| 费用 | $25 | $25 |
| **DUNS** | **不需要** | **必须** |
| 验证材料 | 身份证/护照 + 地址 | 组织文件 + DUNS |
| 开发者显示名 | 个人名 | 公司名 |

**只是想把产品发出去验证 → 走个人账号，完全不碰 DUNS。**

### 5.2 ⚠️ 新个人账号的封闭测试门槛

新注册的个人开发者账号在发布生产版本前需通过封闭测试
（印象中是 **12 名测试者连续 14 天**）。

**这意味着就算账号明天批下来，还要再等两周才能上架。**

测试者招募是纯人工工作、且**不需要账号** —— 建议今天就开始攒名单：

- [ ] 列 15–20 个候选（留冗余，会有人中途退出）
- [ ] 确认每人有 Google 账号 + Android 手机
- [ ] 把测试环境地址发给他们先体验
- [ ] 账号下来后直接邀请进封闭测试

**测试环境地址**（APK 已就绪）：

```
服务端：HOST=0.0.0.0 PORT=8080 python3 server.py

```

## 六、DUNS 速查（若走组织账号）

**第一步：查重**（大公司通常已有，能省 30 天）

```
https://www.dnb.com/duns-number/lookup.html
```

**中国大陆**：由华夏邓白氏独家提供，标准流程约 30 天，加急通常收费。

**失败最常见原因**：组织名称/地址与营业执照不一致
（中文名 vs 英文名、有无 "Co., Ltd."、省市区格式）。

**不要找代理**：DUNS 官方免费，代理可能用不一致信息注册导致验证失败。
