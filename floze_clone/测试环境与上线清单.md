## 二、测试环境部署（今天就能跑）

### 2.1 启动

```bash
cd floze_clone

# 局域网模式（团队 / 手机可访问）
HOST=0.0.0.0 PORT=8080 python3 -u server.py
```

启动后会打印所有可用地址：

```
可用访问地址：
  http://127.0.0.1:8080              ← 本机
  http://192.168.71.82:8080          ← 手机/同事访问用这个
```

**把局域网那个地址发给同事，手机连同一 WiFi 就能直接用。**

### 2.2 默认配置（全部为测试模式，零账号依赖）

| 项 | 默认值 | 说明 |
|---|---|---|
| `AD_MODE` | `test` | 用 Google 官方测试广告位 |
| `PAYMENT_MODE` | `stub` | 充值直接发放，跳过真实交易 |
| `MINIMAX_API_KEY` | 未设 | 未设时为 mock 回复，链路仍可验证 |

**当前状态下，任何人都能完整体验产品**——只是 AI 回复是占位文本、充值不扣真实钱。

### 2.3 前端嵌入 / 打包时的 API 地址

前端支持三种方式指定后端地址（优先级从高到低）：

```javascript
// 1. URL 参数（最方便，适合临时测试）
http://192.168.71.82:8080/?api=http://192.168.71.82:8080

// 2. 全局注入（适合打包成 App / WebView 嵌入）
window.__VESPERINE_API__ = 'http://192.168.71.82:8080';

// 3. 同源（默认，前后端同机时什么都不用配）
```

> **打包提醒**：如果把前端打进 APK 的 WebView 里（加载本地 HTML），
> **必须**用方式 1 或 2 指定后端地址，否则相对路径无处可去。

### 2.4 测试环境配置端点

前端可通过 `/api/config` 读取当前模式，便于显示"测试环境"标识：

```json
{
  "adMode": "test",
  "ad": { "rewarded": "ca-app-pub-3940256099942544/5224354917", ... },
  "paymentMode": "stub",
  "featureFlags": { "realIap": false, "realAdSdk": false }
}
```

## 三、账号并行推进（越早发起越好）

### 3.1 时间线

```
第 0 天  ┬─ 启动测试环境，团队开始体验            ← 今天
         ├─ 发起 Play 开发者账号申请
         ├─ 发起广告账号申请（AdMob）
         └─ 开始攒封闭测试者名单              ← 最容易被忽略，最耗时

第 1-5 天 ┬─ 测试环境迭代、核心玩法打磨
          └─ 账号审核中

第 1-4 周 ┬─ 账号 + DUNS（若走组织）审核
          └─ 封闭测试者已就位

账号下来后 ┬─ 接入真实 IAP / 广告（改环境变量 + 填校验逻辑）
           └─ 启动封闭测试（12 人 × 14 天）

封闭测试后 ── 正式上架
```

### 3.2 三条并行线的具体动作

**线 A：Play 开发者账号**

- [ ] 确定账号类型：个人（$25，不需 DUNS）还是组织（需 DUNS）
- [ ] 若走组织：**先查 DUNS 是否已有** → `dnb.com/duns-number/lookup.html`
- [ ] 若需新申请：确认名称/地址与营业执照**逐字一致**（最常见的失败原因）
- [ ] 注册时「关于您」字段按 `Play账号注册建议.md` 的模板填写

**线 B：广告账号**

- [ ] 注册 AdMob 账号（免费的，审核快）
- [ ] 创建应用 + 激励视频广告位，拿到真实 Ad Unit ID
- [ ] 配置 UMP / GDPR 同意（欧盟必需）

**线 C：封闭测试者名单** ⚠️ **优先级最高**

- [ ] 列出 15-20 个候选测试者（留冗余，因为会有人中途退出）
- [ ] 确认每人有 Google 账号 + Android 手机
- [ ] 测试环境地址发给他们，先体验、收集反馈
- [ ] 账号下来后，直接邀请他们进入封闭测试

> **为什么这条最重要**：新个人开发者账号有封闭测试门槛（我印象中是
> **12 名测试者连续 14 天**）。这意味着**就算账号明天批下来，你还要再等两周**。
> 名单准备、联系、邀约都是纯人工工作，且完全不需要账号 —— 现在就做。
